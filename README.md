 Hospital ER Analytics Dashboard (Excel + Power Query)

## Overview

Developed an interactive **Emergency Room (ER) dashboard** in Excel to analyze patient flow, waiting times, and departmental performance. The project transforms raw hospital data into meaningful insights for operational decision-making.

 ## Tools Used

* Microsoft Excel
* Power Query (Data Cleaning & Transformation)
* Pivot Tables & Charts

## Key Features

* Interactive dashboard with slicers and dynamic filters
* Analysis of patient wait times and treatment duration
* Identification of peak hours and patient trends
* Department-wise case distribution and workload insights

## Data Workflow

* Cleaned and structured raw data using Power Query
* Standardized time-based data for accurate analysis
* Created calculated metrics and KPIs for dashboard reporting

## Outcome

* Enabled clear visibility into ER operations
* Helped identify high-traffic periods and inefficiencies
* Demonstrated practical use of Excel for real-world data analytics
